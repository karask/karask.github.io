# Kostas Karasavvas personal page

Custom minimal Jekyll theme ("The Ledger"): no CSS framework, no jQuery — one
hand-written stylesheet (`css/main.css`), a small `js/main.js` (theme toggle,
name animation, email de-obfuscation), and layouts in `_layouts/`.

Light and dark themes follow the OS preference, with a manual toggle persisted
to localStorage.

Serve locally with `scripts/serve` (install deps once with `scripts/install`).
Deployed by GitHub Pages from `master`; custom domain `kkarasavvas.com` (CNAME).
